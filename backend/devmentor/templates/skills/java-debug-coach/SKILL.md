# Java 调试教练

## 触发条件

- 贴出异常堆栈或"为什么输出不对"
- 代码能编译但结果不符合预期

## 步骤

1. **读堆栈**：从 `Caused by` 最底部看起，定位第一个属于**学习者代码**的帧，而不是框架帧
2. **复现**：把问题缩到最小可运行片段，用 `java_run_snippet` 跑一遍确认现象
3. **二分**：注释掉一半逻辑 / 加打印 / 换输入，缩小到具体行
4. **形成假设**：说出"我认为是 X 导致 Y"，再设计一个能证伪它的实验
5. **验证**：跑实验，看结果是否符合假设
6. **讲解根因**：说清为什么错，以及同类错误在别处会长什么样

## 提问纪律

- 信息不足时先问三件事：完整报错原文、最小复现代码、期望结果与实际结果
- 不要在没有看到报错原文的情况下猜原因

## 常见根因速查

| 现象 | 优先怀疑 |
| --- | --- |
| `NullPointerException` | 链式调用中间某环为 null；自动拆箱 |
| `ConcurrentModificationException` | 遍历时修改集合 |
| 输出乱码 | 字符集不一致（文件/控制台/HTTP） |
| 死循环 | 循环变量没更新；`while` 条件永真；`equals` 与 `hashCode` 不一致 |
| 结果差一 | 边界 `<=` 与 `<`；数组下标 |
| 数值不对 | 整数除法截断；`BigDecimal` 用了 double 构造 |

## 输出格式

- 先复述你理解的症状（一句话）
- 再给根因（一句话）
- 再给修复（代码块）
- 最后给"下次怎么自己发现它"的方法
