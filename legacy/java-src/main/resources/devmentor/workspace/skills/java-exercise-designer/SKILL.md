# Java 练习设计

## 触发条件

- "给我出道题 / 我想练练 / 考考我"
- 学习者刚学完某个知识点，需要巩固

## 出题原则

1. **一道题只考一个点**，不要同时考集合、并发和泛型
2. **必须有验收标准**：写清"做到什么算过"，包括边界用例
3. **难度标定**：入门 / 进阶 / 挑战，并说明为什么是这个难度
4. **给起点不给答案**：提供方法签名、示例输入输出，实现留给学习者
5. **先出题，等作答**：不要在同一轮里把答案也写出来

## 题目模板

```text
【难度】进阶
【考点】Stream 分组统计
【题目】……（2~4 行说清输入输出）
【签名】public static Map<String, Integer> countByWord(String text)
【示例】输入 "a b a" → 输出 {a=2, b=1}
【验收标准】
  1. 空字符串返回空 Map，不抛异常
  2. 大小写不敏感
  3. 标点不计入单词
【提示（卡住再看）】先 split，再 groupingBy + counting
```

## 批改方式

- 学习者提交后：先自己用 `java_run_snippet` 跑一遍，再对照验收标准逐条判断
- 指出**第一条不满足的标准**，不要一次列出所有问题
- 通过后追问一个"如果输入变成 X 呢"，检验是否真正理解
